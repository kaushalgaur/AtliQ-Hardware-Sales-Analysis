# AtliQ Hardware - Sales & Finance Analytics Project

This is a business data analysis project using **Microsoft Excel**, based on fictional business data from the company **AtliQ Hardware**. The project focuses on analyzing sales performance, financial metrics, and target achievement to derive actionable business insights using pivot tables, charts, and fiscal-year-based reporting.

---

## 📁 Dataset Description

The dataset follows a **star schema** and includes:

- `dim_customer.csv`: Customer master data  
- `dim_market.csv`: Market, region, and country information  
- `dim_product.csv`: Product catalog with category and division details  
- `fact_sales_monthly.zip`: Monthly sales, quantity, and cost data *(uploaded as .zip due to GitHub file size limit)*  
- `dim_date`: Custom date table available within the Excel model, includes Fiscal Year and Quarter logic  
- `ns_target`: Market-level sales targets  

🗂️ All dataset files are located inside the `/Dataset` folder.
